Karplus-Strong Harp

Click a string, or press a s d f g h j k. Every string is a tiny feedback loop — a ring buffer full of noise that averages and fades itself, once per sample. Watch the bottom strip: it's the actual delay-line buffer you're hearing, decaying in real time.

click a string to pluck it
how it works Karplus-Strong synthesis: fill a buffer of length N = sampleRate / frequency with white noise, then forever output the next sample and replace it with a damped average of itself and its neighbor. The averaging is a low-pass filter, so high harmonics die first — exactly what a real plucked string does. Push "Character" up and each sample randomly flips sign instead of averaging cleanly, turning the string into an inharmonic drum.
