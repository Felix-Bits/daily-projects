🌀 Burrows–Wheeler Transform Playground

Sort every rotation of a string, read off the last column — and watch text scramble into long runs of repeated characters. That's the trick bzip2 is built on.

Input

Sentinel character $ is appended automatically and marks the end of the string — don't type it yourself. Try "banana", "mississippi", or "the quick brown fox".

1 · All rotations, sorted

Every cyclic rotation of text + $, sorted lexicographically. The last column is the transform output.

2 · Move-to-Front encoding

Each BWT character is replaced by its position in a recency list, then bumped to the front. Repeats collapse to 0 — exactly what long runs in the BWT output produce.

3 · Run-length encoding of the MTF stream

Consecutive equal numbers collapse to (value×count) pairs — the payoff for all that sorting.

4 · Reconstructing the original — from the BWT string alone

Prepend the BWT string to every row, re-sort, repeat n times. The matrix rebuilds itself out of nothing but the last column, over and over.
