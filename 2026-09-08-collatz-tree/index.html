Collatz Tree

Every positive integer, one branch each, all merging toward 1. Built by running the Collatz rule backwards from 1: since every number has exactly one forward successor, the reverse graph is a true tree — no cycles, no merges.

Trajectory

Click any node, or type a number and press Enter. Each node's path back to the root is its Collatz sequence — odd steps zig outward via 3n+1, even steps zag inward via n/2.
