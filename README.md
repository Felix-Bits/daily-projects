# Daily Projects

一个自动更新的小项目仓库：每天生成一个新的小项目，随机涵盖实用小工具、前端小玩具等方向。

每个项目独立存放在以日期命名的文件夹中，例如 `2026-07-19-project-name/`，各自附带简短的 README 说明用途和运行方式。
