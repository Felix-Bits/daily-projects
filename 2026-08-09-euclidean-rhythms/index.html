Euclidean Rhythms

Each ring spreads k beats as evenly as possible across n steps — the same algorithm behind flamenco claps, West African bell patterns, and the Cuban tresillo. Turn the wheels and listen to the maths.
Click any step-dot directly on the wheel to toggle it by hand. Sounds are synthesized live with the Web Audio API — no samples, no dependencies. Tempo, pulses, steps and rotation are all live-tweakable while playing.
